# EASY1 homepage composition previews

Open `index.html` directly in a browser. The comparison controls select A (Editorial) or B (Projects). Both adapt to desktop and mobile. These are local design-review documents; they are outside the application/public directory and do not implement website routes or wallet flows.

A uses a spacious split hero with decorative connections between the approved Connected Soft identity and official product icons, then a two-column grid for four projects. B uses a compact type-led hero and larger product rows, bringing actual product imagery closer to the top. Both keep the approved section order and navigation direction.

The product images are actual public landing-page captures. Source URLs, timestamps, HTTP status and viewports are in `capture-provenance.json`. Visible interface elements inside those images belong to the captured websites; the images do not implement those controls. Homepage project links now open full Editorial overview drafts with onward product links. Navigation reaches the Pool, About and Blog page drafts. The static filenames are review locations, not final application route decisions.

Copy is proposed for review. The portrait is explicitly a placeholder. Pool figures are unavailable placeholders, not invented metrics. “Inside AdaMatic” was confirmed by Giovanni as the third upcoming title on 2026-10-13. Article cards are labelled Coming soon and have no unwritten-article links. Public-intended blog cards contain no article body, link or publication date. A separate `article-layout.html` sample uses lorem ipsum, with an explicit layout-only label and reviewer-only link; it is outside the intended public launch.

The palette and identity come from the delivered brand kit. Poppins SemiBold is loaded from that kit, where its font and SIL OFL licence are included; serif accents use the system Georgia font. This visual exploration proposes typography and layout; it does not override the existing application stack.

To share the review over a local network, serve an isolated copy containing only this preview directory, `docs/brand-research/logos` and `easy1staking/public/brand`, preserving their relative paths. Keep private repository files outside the server root. Do not start current main's application scripts, which execute its unreviewed api.js. Application build/lint evidence is separate, in `../baseline-check.json`.

Cardano Dev Skills was added on 2026-10-13. Creator/handover attribution comes from Giovanni’s first-hand statement. Current project description, location, icon/header mark and screenshot come from the official Cardano Foundation site/repository. It is included as originated work, not presented as a currently owned EASY1 product.

Full-page drafts: `adawatch.html`, `adamatic.html`, `uplc-link.html`, `cardano-dev-skills.html`, `pool.html`, `about.html`, `blog.html` and the layout-only `article-layout.html`. Pool’s preview control opens a layout explanation; it never accesses wallet APIs. `page-preview-manifest.json` describes scope, and `page-journey-checks.json` records the observed HTTP review checks across nine pages and four widths. Final biography, portrait, release routes and implementation remain to be finalized.

`review-plan.html` summarizes the consolidated implementation-phase proposal and its remaining product/technical choices. `specification.txt` and `component-layout.txt` mirror the product-only root documents; both are review drafts, not a locked release contract.
