# Launch discovery and future writing

The eight current pages are `/`, `/about`, `/blog`, `/pool` and the four project overviews at `/projects/adawatch`, `/projects/adamatic`, `/projects/uplc-link` and `/projects/cardano-dev-skills`. Their canonical origin is `https://easy1staking.com`. `/sitemap.xml` lists exactly these pages without invented modification dates; `/robots.txt` permits crawling and points to that sitemap. The brand gallery and ZIP remain at `/brand/index.html` and `/brand/easy1staking-brand-kit.zip`.

Homepage fragments `#projects` and `#pool` identify the current sections. The browser bridge replaces old `#contribution` with `#projects` and old `#delegate` with `/pool#delegate`. Replacing the legacy history entry avoids a redirect loop when navigating back. The delegation destination is the existing read-only pool notice: wallet connection and in-site delegation remain unavailable. Unknown fragments and fragments on other pages are preserved. Fragments are handled in the browser because HTTP requests do not carry them. Reduced-motion preferences disable animated scrolling; fragment targets support keyboard focus.

`ArticleLayout` is a render-only component for future approved writing. Callers must supply a nonempty title and author, a real ISO calendar date (`publishedAt`, `YYYY-MM-DD`) and trusted React children. Text is escaped by React; the layout does not accept HTML strings or fetch content. Its styles cover headings, paragraphs, lists, links, quotes, code and responsive images. Long code can scroll within its own block; callers should give long code blocks `tabIndex={0}` for keyboard access and provide meaningful image alternatives and dimensions. This component creates no article route, sample body, publication date or sitemap entry. The current Blog cards remain Coming soon.

To reproduce locally, use Node 24, enter `easy1staking/`, install the lockfile with `npm ci --ignore-scripts`, then run `npm run build`, `npm run lint` and `npm run start -- --hostname 127.0.0.1 --port 3000`. Do not use the destructive `clean` script. Leave the public Blockfrost configuration unset to check unavailable facts without provider calls. Visit the eight pages, the discovery files, each fragment above and an unrelated fragment; confirm that no wallet prompt opens. Check the real gallery/downloads and native image delivery. Existing migration responses are documented in `docs/migration.md`.

Release preparation still requires the guarded wallet flow, independent transaction/ledger evidence, current pool and provider validation, credential rotation and old deployment containment. Development dependency repairs and inspection of the exact deployable filesystem, inventory and exclusion scans remain separate work. This change establishes neither complete release readiness nor public article publication.
